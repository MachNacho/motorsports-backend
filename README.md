This is the backend API for the Motorsports website frontend

## How to run

Clone the Repo

Run dotnet restore for the packages

Add the DB connection string to the appsettings.development.json

Run the update-database command in package mangaer console

Run the API by clicking the green button on top

Use https://localhost:7016/scalar/ to view the endpoints
